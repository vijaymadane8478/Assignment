Objective: 

Create a simple application that consumes the JSONPlaceholder API to display post data. You will work only with the /posts endpoint. 

List Page 

 Fetch all posts from https://jsonplaceholder.typicode.com/posts. 

Display the list of posts showing: 

Post title 

Short preview of the body 

Clicking on a post should navigate to the Details Page. 

Details Page 

Display full details of the selected posts 

Title 

Body  

Provide a back navigation to the List Page.
